What happens when you connect

  1. State and PKCE. The API stores a one-time state and an S256 code verifier in HttpOnly cookies, then refuses any callback that does not carry the same state.
  2. Server-side exchange. Only the API trades the code for a token. The token is sealed with AES-256-GCM before it reaches MongoDB and never appears in a URL or in this page.
  3. Hashed session. This browser gets a random HttpOnly session id for eight hours; the database keeps only its SHA-256 hash, so a database dump cannot be replayed as a cookie.
